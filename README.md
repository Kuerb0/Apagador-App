# Apagador

Programador de apagado de Windows con interfaz gráfica (Python + tkinter). Eliges una duración en minutos o una hora exacta y lo puedes cancelar en cualquier momento, incluso durante la cuenta atrás.

- **Instalar:** descarga el instalador de la [última release](https://github.com/Kuerb0/Apagador-App/releases/latest). Se instala en tu usuario, sin permisos de administrador.
- **Desde el código:** `python apagador_app.py` (necesita Python 3 con tkinter).

Forma parte del [portal](https://kuerb0.github.io/portal/).
